# 曜衡智控：燃气智能检测 Agent

面向燃气业务的智能检测平台，提供每日巡检、计量异常分析、设备健康诊断、安全作业监测、智能问答和技术文档知识库。

## 快速开始

### 1. 安装与配置

准备 Python 3.12、uv、Node.js、npm 和本地 Qdrant。在项目根目录执行：

```powershell
uv sync
npm --prefix frontend install
Copy-Item .env.example .env
```

已有 `.env` 时跳过复制。根据需要填写配置：

| 功能 | 配置项 |
| --- | --- |
| 智能解读 | `DEEPSEEK_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` |
| 智能问答 | `CHAT_LLM_*`，具体选项见 `.env.example` |
| 安全作业视频复核 | `ARK_API_KEY`、`ARK_MODEL_ID`、`SAFETY_AGENT_TOKEN` |
| 知识库检索 | `DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID` |
| PDF 解析与识图 | `RAG_DOCLING_PYTHON`、`RAG_VISION_*` |

知识库解析需要单独准备已安装解析、OCR 和分块组件及模型缓存的 Docling 环境，并用 `RAG_DOCLING_PYTHON` 指定其 Python 路径。识图密钥和地址未填写时沿用通用模型配置。修改配置后重启后端。

业务诊断依赖本地数据和模型，安装依赖不会自动生成它们。数据重建与维护入口见 [脚本说明](scripts/README.md)。

### 2. 启动平台

```powershell
.\start_api.ps1
```

脚本会检查并启动本地 Qdrant，再启动前后端。Qdrant 默认目录为 `D:\Qdrant`，可通过 `-QdrantDir '你的目录'` 指定。

- 平台入口：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)
- API 文档：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- 演示账号：`admin` / `123456`

按 `Ctrl+C` 停止前后端。

如需使用构建后的前端：

```powershell
npm --prefix frontend run build
.\start_api.ps1 -ApiOnly
```

启动后访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

## 功能使用

### 每日全量巡检

选择检测日期，查看当天的企业诊断汇总、异常企业、风险等级和高频问题，再进入计量或设备页面查看详情。

### 智能计量

选择企业和日期，查看用气曲线、计量异常、压力与温度异常、量程运行情况及补气量估算，结合证据和核查建议排查问题。

### 智能设备

选择具有振动数据的企业和日期，查看设备健康阶段、健康指数、振动特征和近期变化趋势。健康阶段分为 H0 健康稳定至 H4 故障异常。

计量和设备页面均可点击“生成智能检查结果”获取解读，也可先填写现场补充信息。系统设置中的“Agent 自动解读”默认关闭，开启后会在企业、日期或模块变化时自动解读当前详情。

### 安全作业

先配置视频复核参数，再运行视频检测：

```powershell
uv run python -m intelligent_detection_agent.safety_operations.monitor `
  --config .\safety_operations\config.yaml `
  --source 'E:\path\to\video.mp4'
```

检测和复核完成后，在“安全作业”页面查看异常截图、复核视频、人员防护装备（PPE）结论及待人工复核事件，并执行确认、处理或关闭操作。事件关闭后，操作人和备注不可编辑。

### 智能问答

进入“智能问答”，直接用自然语言查询业务数据、分析异常或检索技术文档，例如：

- “2025 年 1 月 12 日有哪些计量异常企业？”
- “分析这家企业最近一周的设备健康趋势。”
- “超声流量计单向测量应如何安装？”

支持多轮追问、历史对话、图表报告和 HTML 报告下载。创建工单前会请求人工确认；安全事件的确认、处理和关闭需在“安全作业”页面完成。

### 知识库

进入“知识库”上传 PDF，选择全文或连续页码范围，等待解析和索引完成后，即可在智能问答中检索内容。

- 默认单文件上限为 100 MiB；相同文件和页码范围不会重复入库。
- 扫描件或文字乱码时，开启“强制 OCR”。
- 处理失败可查看原因并点击“重试”；刷新页面不会中断后台任务。
- 删除文档后，该文档不再参与后续检索。

## 使用说明

- 当前示例业务数据主要覆盖 **2024-12-25 至 2025-01-12**，查询和诊断请选择有数据的日期。
- 补气量为算法估算，需经现场核查和企业计量规则确认后才能用于结算。
- 设备振动退化数据包含合成样本，不能作为现场真实寿命记录。

更多配置见 [.env.example](.env.example)，维护命令见 [脚本说明](scripts/README.md)。
